# Experiments

This directory follows the Evaluation section of the paper.

- `correctness/`: topology and OpenFHE split-path preflight checks;
- `performance/`: client-scaling and local runner measurements;
- `baseline/`: controlled comparison variants;
- `ablation/`: component ablation placeholders;
- `utility/`: MNIST/CIFAR trajectory-preservation sanity checks;
- `configs/`: YAML profiles.

Generated outputs should be written to `results/`, not committed to source control.
