# Security Policy

This repository is a research artifact. It is not production software.

Please do not report ordinary research limitations as vulnerabilities. The paper
explicitly excludes malicious security, dropout recovery, network anonymity,
production deployment hardening and concrete 128-bit post-quantum security-bit
claims.

For artifact issues, report:

- code paths that contradict the paper protocol;
- reproducibility failures in the documented smoke tests;
- accidental inclusion of private data, keys, raw logs or generated binaries;
- correctness failures in the evaluated parameter profile.
